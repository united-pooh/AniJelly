# 夜航 · NIGHT SIGNAL 设计检查清单

本文件用于四屏高保真原型的设计评审，不是已完成功能清单。目标是让拥有 NAS 番剧库的人安静地选一部、找到正确的一集与版本、进入观看。正式产品仍为 AniJelly；“夜航”是本轮视觉提案名。

## 1. 统一方向与验收方法

- 影院蓝黑 `#0D0E12`、内容底 `#12141A`；主文字暖白 `#F4F1EC`、次文字 `#9DA4B4`。主作海报粉 `#E7A7BF` 与青 `#9CBECF`，另一作品可以转为紫 `#ACA0DB`。海报色影响氛围，不改变错误、已选、焦点的语义。
- 中文使用内嵌 NightCJK 子集，Latin 标题使用 Avenir Next / Futura，时间码使用 SFMono / Menlo。均保留系统字体回退；中日英混排不能挤压行高。正文以 16px 为基准，辅助信息与控件文字逐屏检查可读性，输入文字保持 16px。
- 常规控件圆角 14px、海报圆角 10px；导航和播放器可使用玻璃层，CRT 登录使用 5–6px 小圆角的平面控件。内容分区靠留白与排版区分，不给每行元数据套玻璃卡片。
- 记忆点集中在“唤醒一台深夜 CRT，在屏幕里进入影院”。登录前后保持同一台显示器的固定构图；进入片库后退场为安静的电影画廊，不把扫描线、噪点、辉光和故障动画铺满四屏。
- 至少实看桌面 1280×720 与手机 390×844；播放器另看横屏 844×390。长标题、缺海报、空库、错误、打开抽屉、键盘焦点和减少动态分别验收。所有勾选需要截图或交互记录，不能仅据源码标记通过。

## 2. 四屏关键验收

### 首页：五秒内找到可看的内容

- [ ] 首屏以一幅 fanart 和一部作品为中心；中文名、最多两行简介、继续观看／开始观看、查看详情构成明确顺序。不摆放 NAS 指标、编码参数、产品宣言或 API 状态。
- [ ] 有进度时主动作写“继续第 7 集”，附近显示“已看 10:42”，不用含糊的“继续旅程”。没有进度时写“开始观看”。
- [ ] 桌面侧栏默认 72px 图标轨道，可主动展开；图标有名称，展开不挡住当前主动作。手机使用显式菜单，不能挤出横向页面滚动。
- [ ] 横排依次承担真实目的，如“继续观看”“最近入库”“我的收藏”；一张海报代表一部作品，不把同集不同清晰度重复放成推荐卡。卡片标题始终可见，触屏无需 hover 才能获得必要信息。
- [ ] 方向键或触摸可到达 rail 最后一项，末尾留有余量；焦点卡片滚入视野，缩放与焦点环不被父容器裁掉。滚动位置在从详情返回时保留。
- [ ] 空库只说明下一步；普通用户看到“请联系管理员添加番剧”，管理员看到“添加媒体库”。加载失败与空库不同，不能用空态掩盖错误。

### 详情：先认作品，再选集，再选版本

- [ ] 第一层为中文标题，第二层为日文／英文别名；别名可折叠，不与主标题争抢。紧随其后是年份、题材、集数与收藏／观看状态，简介约三行后展开。
- [ ] 主动作与当前观看进度相连；海报、背景和标题重复表达同一作品，不能一边已切换作品、一边保留上一部的色彩或进度。
- [ ] 季与 Cour 构成章节，不成为三套互相竞争的 tab。“第 1 季 · 前篇（1–12）／后篇（13–24）”明确集数范围；Cour 不是自动推断的新一季，特别篇单列。
- [ ] 一行是一集：集号、标题、时长、观看进度。行内“2 个版本”打开当前集的选择器；选项说明来源、分辨率、视频格式、音轨与字幕，长技术名收进详情层。
- [ ] 未下载／未入库一集明确标记“尚未入库”，不显示可执行的播放按钮；不把“已入库 18/24”写成已播出集数。
- [ ] 信息抽屉承载制作信息、文件与轨道详情。打开后焦点进入，关闭回到触发按钮；小屏抽屉独立滚动，标题与关闭动作不会被内容挤走。

### 播放器：画面优先，操作有确定结果

- [ ] 画面不拉伸；标题轻量置顶，底部进度与核心控件在安全区内。鼠标移动、触摸、键盘和手柄动作均能唤出控件；暂停、菜单展开、控件聚焦时不自动隐藏。
- [ ] 进度条可点选、拖动和键盘调整；预览缩略图带对应时间。无缩略图时仍显示时间，不伪造实时抽帧。触屏长按／拖动不依赖桌面 hover。
- [ ] 音轨、字幕、版本选择各有当前值与明确选中态；打开菜单不挡住关闭按钮，不同时展开多个面板。切换成功后再更新结果文字，失败保留原选项。
- [ ] OP/ED 操作贴近进度控制的右上方，不压住底部字幕；只在播放头进入对应已知区间时出现“跳过片头／跳过片尾”。未知区间不显示万能按钮。
- [ ] 真实接入时跳到当前媒体版本区间的结束时间，不能写死“快进 90 秒”。不同剪辑、预告、片头长短要绑定媒体源；无可靠对应区间时先隐藏。片尾跳转与“播放下一集”是两个动作，不自动越过片尾彩蛋。
- [ ] 弹幕有独立开关；字幕与弹幕层不夺取播放器焦点。原型样例弹幕为本地演示，不出现“已发送”或在线人数等会暗示联网成功的状态。
- [ ] 返回详情后选集、版本和进度仍一致；菜单关闭与返回页面不共用一个含混动作。播放失败可重试或换版本，错误不把整个画面锁死。

### 统一 CRT 登录：仪式可以跳过，可用性不能跳过

- [ ] 首屏为一台固定构图的 CRT，屏幕内明确显示“开始”，机壳下沿保留品牌、跳过和静音控制。登录页隐藏四屏评审栏；表单直接出现在屏幕内，不增加屏幕外输入面板。
- [ ] 用户点击唤醒后，音画由同一次状态推进：亮线、背景对焦、约两秒后显示表单并聚焦昵称。快速双击不会叠加音效；等待过程中可跳过，表单就绪后收起跳过动作。
- [ ] 表单显示昵称、口令和“进入放映室”。任意非空昵称与口令只用于原型入场校验，说明不采集真实 NAS 密码；口令提交后立即清空，不保存、不发送。
- [ ] 成功后表单收起、CRT 与底座约 600 毫秒整体淡出再进入首页。重复提交不重复跳页，途中离开或重新显示登录页会取消旧回调；安静模式与减少动态直接显示表单、直接入场。
- [ ] 扫描线和反光层在表单下方，滤镜和一次轻微错误 glitch 只作用于背景图片。昵称、口令、按钮和错误文字始终清楚，不能继承父容器模糊。
- [ ] 错误文字直接说明操作，例如“请填写你的昵称”；保留昵称、聚焦相关输入，错误持续可读且由 `aria-live` 宣告，不把原型非空校验写成真实认证失败。
- [ ] 手机软键盘打开后输入与提交可随页面滚动到达，不能被 CRT 外框裁切。粘贴与正常键盘操作保留，演示口令不诱导保存为真实账号密码。

## 3. 交互与信息结构细则

### 海报主色与元数据

- [ ] 每部作品提供一组稳定的背景色和强调色；卡片经过即刻扫过时不连续闪烁，停留约 180–250ms 或明确聚焦后才切换 hero。正在读简介时不自动轮播。
- [ ] 海报主色只进入低亮度背景、边缘与细节；文字下方有稳定暗色衬底。主色过亮、过灰或图片缺失时回到影院底色，不让整页变成明亮色块。
- [ ] 检查最亮背景下普通文字对比度至少 4.5:1，大字与必要控件边界至少 3:1；进度、选中和错误不能仅凭颜色区分。
- [ ] 元数据缺失就省略，不显示 `null`、0 分或虚构评分。评分如作为设计样例必须标为示例且注明来源类型；本清单的作品不安排评分。
- [ ] 收藏是用户动作；“继续观看”来自进度；“最近入库”来自入库时间；“连载中”来自作品状态。四者不混为统一彩色徽章。

### 同集聚合与 Cour

- [ ] 聚合锚点为作品、季、集号及特别篇标识，不以文件名相似或分辨率相同合并。上下合辑、总集篇和不同剪辑不能无说明地当成同一集。
- [ ] 默认版本有可解释规则，例如“上次使用的版本”；未确定规则前原型只展示“当前选择”，不伪称智能择优。选择器不暗示所有客户端均可直放某种编码。
- [ ] 切换不同长度的版本不能直接沿用百分比作为精确播放位置；正式接入需明确时间映射或让用户重选起点。原型使用等长版本演示。
- [ ] 首页统计按集计数，版本数量另外显示；Cour 切换只改变剧集分组，不重置作品进度。已入库、未入库、已看完和正在看必须分别可辨。

### 焦点、减动态、音量与预载

- [ ] 键盘全流程可用：Tab 到达动作、Enter 执行、Esc 关闭最上层；焦点环持续可见。rail 导航不会拦截输入框的方向键。
- [ ] 若实现手柄：方向键／摇杆移动空间焦点，确认键执行、返回键退一层；跨 rail 后返回相近列，长按有节制的重复移动，摇杆漂移不连续触发。未接入 Gamepad API 时交付说明只写“键盘方向键演示”。
- [ ] `prefers-reduced-motion` 下关闭 CRT 闪烁、glitch、空间缩放、背景漂移；直接进入清晰静态状态，错误和步骤反馈仍完整。任何模式都不使用快速全屏明暗闪烁。
- [ ] 声音开关明确标注低音量或静音；只在用户主动点击“开始”后启动合成音效，总增益不高于 0.08。记忆静音偏好，刷新与跨屏不悄悄复位；浏览器拒绝声音时继续静态流程。记忆偏好不等于获准自动有声播放。
- [ ] 初载优先首屏 fanart 和当前作品；其余海报按可见范围解码／预载。播放器只为当前样例准备必要资源，不能为六部作品同时启动视频或音频解码。
- [ ] 页面隐藏或离开登录／播放器时停止不必要的计时与音效；静态背景不运行逐帧脚本。单文件图片与中文字体子集内嵌，其他字符有本地回退；“离线可看原型”不等于 NAS 媒体离线缓存。

### 海报标题排版建议

- **蓝色时差**：中文四字分两行，字间距克制；英文小号宽字距置下，日文收在海报边缘。横幅中标题不要压过人物眼睛或收音麦克风。
- **雨季天文台**：中文横排一行或两行居上，英文窄字宽，穹顶留完整轮廓；不要追加无意义的星图数字。
- **纸月旅馆**：中文竖排可作为单张海报的变化，界面标题仍横排可读；英文沿底边，字形纤细但不能发虚。
- **逆光赛道**：中文略紧凑，英文可斜体但不整块倾斜；字色取浅珊瑚，海报中不放车辆参数。
- **白潮档案**：中文偏左下，英文小号置于潮线之上；以留白形成悬疑，不模仿真实案件档案公章。
- **山眠之后**：中文居中偏上，字距略松；英文两行靠底，用纸灯的暖色形成唯一亮点。

## 5. 原型与真实能力边界

| 原型可以演示 | 不能据此声称已经实现 |
| --- | --- |
| 预设六部作品、海报色切换、收藏与浏览状态 | NAS 扫描、刮削、实时色彩提取、真实推荐或作品授权 |
| 季 / Cour 分组、同集版本选择 | 根据任意现有文件自动正确分组，或所有版本无缝切换 |
| 静态画面、模拟时间轴、OP/ED 指定区间 | 实际解码播放、转码、自动识别 OP/ED、缩略图提取 |
| 本地示例弹幕、音字幕菜单 | 在线弹幕服务、字幕下载、真实轨道切换 |
| CRT 动效、示例账号、静音偏好 | 正式身份认证、密码存储、用户权限或会员服务 |
| 键盘／明确已实现的手柄交互 | 所有遥控器、电视浏览器或硬件设备兼容 |

当前服务端已有媒体源协商、进度、版本与媒体片段等相关契约；媒体片段识别仍需要具体 provider，客户端也需要接入。原型选择器或跳转按钮不等于完成这条链路。设计模式标识和演示说明放在说明入口或交付文档，不能占据作品 hero 的主标题、简介和主动作区域。
