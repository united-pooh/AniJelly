# 夜航 · NIGHT SIGNAL

夜航是连接 AniJelly / Jellyfin 的私人影院客户端，保留深夜画廊与 CRT 登录的视觉系统。登录、媒体库、收藏、剧集详情和播放均使用当前服务器的数据；不再用虚构作品、任意口令或模拟时间轴填充正式路径。

交付入口为本目录的 [夜航私人影院.html](夜航私人影院.html)。[组装脚本](build.py)将 `parts/` 的样式与脚本、登录装饰图、中文字体子集和 hls.js 内嵌为一个 HTML。界面资源不依赖 CDN，但认证、图片、元数据和视频需要可访问的 Jellyfin 后端；直接离线打开文件不能独立登录或播放。容器通过同源 `/api/` 接入已有服务器，部署方式见 [容器启动说明](容器启动说明.md)。

本说明描述当前实现及边界，不代替运行证据。新版实测记录汇总于 [真实客户端验收](../../.agent/visual/night-real-validation.md)，具体浏览器、媒体样本和部署版本以该记录为准。

## 视觉系统

深色背景与留白承托媒体图像、标题和观看位置，技术信息在选择版本、轨道或查看媒体信息时出现。

| 元素 | 当前用途 |
| --- | --- |
| 背景 | 影院蓝黑 `#0D0E12` 与内容底 `#12141A`；内容区保持平面层级 |
| 文字 | 主文字暖白 `#F4F1EC`，次文字 `#9DA4B4`；字号、字重和留白区分层级 |
| 强调色 | 粉 `#E7A7BF`、青 `#9CBECF` 用于局部强调，不宣称已按真实海报自动取色 |
| 字体 | 中文优先内嵌 NightCJK；Latin 使用 Avenir Next / Futura，时间码使用 SFMono / Menlo，并保留系统字体回退 |
| 形状 | 常规控件约 14px 圆角，海报约 10px；导航与播放器保留玻璃层，CRT 表单为平面控件 |
| 动态 | 登录约两秒亮屏与背景对焦，认证成功后约 600 毫秒整体淡出；安静模式和系统减少动态可跳过这些转场 |

同一台深蓝灰工业 CRT 承载待机、唤醒和屏幕内登录表单。扫描线和反光位于表单下方，滤镜只影响背景画面，不模糊输入和文字。此前用于四屏评审的快捷导航已退出当前界面。

中文子集来自 Noto Sans Mono CJK SC 2.004，CSS 名称为 `NightCJK`，并通过 `unicode-range` 限定中文与相关标点，不接管 Latin 排版。资源大小和覆盖范围以 [字体清单](assets/night-cjk-manifest.json)及 [字体说明](assets/字体说明.md)为准。服务器返回的片名、人物名和简介不属于固定文案全集；子集外的字符由系统字体显示。完整字体许可证随 HTML 内嵌。

## 登录与首次设置

登录页先读取服务器公开信息。已经完成设置的服务器使用真实用户名、密码认证；未完成设置时由用户在 CRT 中填写首位管理员信息，并依次创建管理员、认证、完成首次设置。客户端不会替用户预设账号或自动填写密码，也不提供普通用户自助注册。若管理员已经存在而首次设置尚未完成，可切换到已有账号登录。

“跳过片头”只跳过装饰动画，不能跳过认证。密码提交后立即清空输入框，交由服务器验证，不存入客户端会话。首次设置要求非空密码；已有账号是否允许空密码由服务器决定。连接失败、无权限与认证失败显示可读错误，可重试；错误动效仅作辅助提示。

CRT 背景仍为原创首帧插画的轻微动效，不是从收藏夹抽取的视频片段。音效由用户点击后通过 Web Audio 低音量合成，离开或隐藏登录页会停止音效和动画任务。静音与安静模式尝试保存在 `localStorage`，存储不可用不阻断认证。

访问令牌与当前用户保存在本标签页的 `sessionStorage`，刷新时通过 `Users/Me` 重新验证。退出先停止播放器并发送停止报告，再调用服务器退出接口、清理本地会话及媒体界面；认证失效也会清理受保护内容并回到登录页。设备标识和声音偏好可以留在 `localStorage`，它们不是登录凭据。未登录的首页、详情及播放深链均受路由门禁保护，数据权限仍由服务器执行。

## 首页与详情

桌面使用 74px 图标侧栏，手机收窄为 54px，可主动展开名称。首页读取用户可见的媒体库、继续观看、最近入库和收藏；库选择、搜索、片库和收藏分页均向服务器查询。当前浏览范围是电影、剧集与视频，不把这个界面描述为完整音乐、照片或图书客户端。

海报和背景来自服务器图片接口。没有图片时使用中性纯色与真实标题，不替换为虚构作品海报；空库显示空状态，请求失败显示错误及重试，不能把连接失败当成“没有媒体”。缺少的年份、演职员、简介等元数据省略，不补写假统计或评分。

详情读取真实条目、季和剧集，季编号与名称沿用服务器数据，特别篇由服务器的季结构表达。每集展示可用的标题、时长、已看和续看信息；虚拟或缺失媒体不提供播放动作。相关推荐来自服务器相似条目接口，不绘制虚构作品关系图。

收藏操作由服务器确认后更新界面。切换账号或路由时，过期请求不能覆盖当前页面的收藏状态。媒体信息面板展示服务器实际提供的容器、时长、大小、视频、音轨和字幕；多版本选择放在播放器中，不根据文件名虚构字幕组、Cour 或版本来源。

## 播放与进度

播放器使用真实 HTML5 视频与 `PlaybackInfo` 协商结果。可兼容的来源直接播放；需要转换时使用服务器提供的转码流。浏览器不能原生播放 HLS 时使用内嵌 hls.js。是否能播放具体编码、色彩格式或字幕，仍取决于浏览器能力、用户权限和服务器转码条件，不能由菜单存在推断为全部格式已验证。

HEVC 10-bit 先检查浏览器的 `canPlayType` / Media Source 支持，并在可用时通过 MediaCapabilities 查询解码能力，再向服务器声明直放或 fMP4 视频复制候选。播放方式依据服务器实际会话区分“原片直放”“仅重封装”“视频直通、仅音频转码”和“视频转码”；无法确认时明确显示未确认。HDR 源视频未转码不等于显示器已经呈现 HDR。Windows 用户需使用支持该格式的 Edge / Chrome、开启系统 HDR 并连接兼容显示器；本轮尚未验证 Windows 实体显示器上的 HDR 成像，也不宣称所有 HDR / Dolby Vision 格式均可保留。视频已转码时界面提示 HDR 不保留。

版本、音轨和字幕选项来自服务器的媒体源与流信息。文本字幕可通过服务器 VTT 接口加载，其他情况按播放协商结果处理，不声称具备完整客户端 ASS 特效渲染。切换版本或轨道会重新协商，沿用真实视频当前秒数，并按新版本时长限制范围；不把不同剪辑的相同百分比当成精确位置映射，也不把任意媒体源 ID 猜成可查询的条目 ID。

续看读取条目的服务器用户数据；开始、周期进度、暂停、跳转和停止报告写回服务器。页面时间轴由视频实际时间驱动，下一集来自服务器返回的相邻剧集。网络失败会提示进度未同步，不能承诺未送达报告也已保存；此客户端没有另建离线进度数据库或多人同步播放机制。

片头、片尾按钮仅使用服务器返回的媒体片段区间。当前来源不能确认与原条目匹配时，不沿用另一剪辑的区间。没有有效片段数据就不显示跳过动作；客户端本身不识别 OP/ED。时间轴预览显示时间码，不伪造服务端抽帧。弹幕服务、假字幕组、假评分和演示关系图均不在当前功能中。

## 验收与历史

键盘焦点、390px 手机布局、CRT 减少动态、错误状态、真实播放和退出清理需与实际后端一起验收。`npm test` 的模拟 DOM 与 API 契约测试不能替代真实浏览器的视频解码和容器检查；运行与部署结论统一记录在 [真实客户端验收](../../.agent/visual/night-real-validation.md)。

以下记录均为接入真实后端之前的历史版本，不能证明当前客户端已通过同样的场景：[初版四屏验收](../../.agent/visual/night-signal-validation.md)、[初次容器验收](../../.agent/visual/night-signal-container-validation.md)、[统一 CRT 验收](../../.agent/visual/night-signal-crt-validation.md)。[初版设计检查清单](设计检查清单.md)保留原设计目标，其模拟数据相关要求不再代表当前实现。
