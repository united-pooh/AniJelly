# 夜航中文字体子集

两个 WOFF2 来自本机已有的 **Noto Sans Mono CJK SC 2.004**（Regular / Bold），原始字体由 Adobe 设计，以 SIL Open Font License 1.1 发布。本次子集生成不下载新字体，不安装或修改系统字体。

| 文件 | 字重 | 大小 | 子集字体名称 |
| --- | --- | --- | --- |
| [night-cjk-regular.woff2](night-cjk-regular.woff2) | 400 | 146,960 字节，143.52 KiB | Night Signal CJK Regular |
| [night-cjk-bold.woff2](night-cjk-bold.woff2) | 700 | 149,956 字节，146.44 KiB | Night Signal CJK Bold |

为区分修改后的子集，family name 为 `Night Signal CJK`，PostScript 名称为 `NightSignalCJK-Regular` / `NightSignalCJK-Bold`。原版权、作者和许可证 metadata 保留，不把原作者描述为夜航的背书方。

## 覆盖与接入

脚本自动收集 `parts/` 中全部 HTML 和 JavaScript，包括真实 API 客户端 `api.js`。本次输入为 3 份 HTML、4 份 JS，加入常用中文标点后共请求 487 个 Unicode 码点。两个输出各覆盖 487 个码点、1,172 个字形（含布局替代字形），总大小为 296,916 字节。当前请求的字符全部覆盖，原字体缺字清单为空。

这些是固定界面文案的覆盖结果，不表示覆盖服务器里所有片名、简介和人物名。真实媒体元数据中的其他字符使用系统字体回退；子集不是完整中文字库。

原字体的 Latin 为等宽字形，接入时不让此字体接管 Latin / ASCII。正常比例的 Latin 字体先行，两个 `@font-face` 限定中文与全角标点范围：

```css
font-family: "Night Signal CJK";
font-weight: 400; /* 另一份为 700 */
unicode-range: U+2E80-2EFF, U+2F00-2FDF, U+3000-303F, U+31C0-31EF,
               U+3400-4DBF, U+4E00-9FFF, U+F900-FAFF, U+FE10-FE1F,
               U+FE30-FE4F, U+FF00-FFEF;
```

[build.py](../build.py)以 CSS 名称 `NightCJK` 把两个子集内嵌到单文件 HTML，应用上述范围并保留系统字体回退。因此字体资源可随 HTML 本地加载，但不能据此离线完成真实登录或播放。新增界面文案后需重新生成子集，再重新组装 HTML。输入文件 SHA-256、请求码点、字体字重与名称、输出和原始字体摘要、缺字清单见 [manifest](night-cjk-manifest.json)。

## 许可证与分发

官方来源：[Noto CJK Sans LICENSE](https://github.com/notofonts/noto-cjk/blob/main/Sans/LICENSE)，其 [Raw 原文](https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/LICENSE)保存为 [OFL-NotoSansCJK.txt](OFL-NotoSansCJK.txt)。原字体内版权声明为 `© 2014-2021 Adobe (http://www.adobe.com/).`，许可证文件摘要记录于 manifest。

子集仍按 OFL 1.1 分发，随应用保留原版权与完整许可证。字体不能单独出售，也不将其改标为应用代码的其他许可证。单文件 HTML 已将完整 OFL 原文放入可查看的 HTML 注释；原始 OTF 不随应用分发。

## 生成与验证

生成工具 [sources/subset_fonts.py](../sources/subset_fonts.py)使用 Python、fontTools 和 Brotli；本次使用 fontTools 4.62.1、Brotli 1.2.0。提供 Noto Sans Mono CJK SC 2.004 两个原始 OTF 后执行：

```sh
python sources/subset_fonts.py --regular-font /path/to/NotoSansMonoCJKsc-Regular.otf --bold-font /path/to/NotoSansMonoCJKsc-Bold.otf
```

脚本以自身位置定位 `parts` 和 `assets`，自动包含新增 HTML / JS，不再假定模块总数固定。它只重写两个 WOFF2 与 manifest，生成后重新读取字体，核对字形覆盖、字重、改名、版权和许可证 metadata，并核对原始字体及输入模块在处理期间未变。完成后由 `build.py` 把更新后的字体嵌入 HTML。
