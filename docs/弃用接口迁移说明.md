# 弃用接口迁移说明

> 2026-10-12；基于 `a45d1415d4` 的清理后工作区。配套：[开发者功能手册](开发者功能手册.md)、[当前 API 索引](API功能入口索引.md)。

本次删除 13 个控制器中的 **50 个 `[Obsolete]` 动作、53 条 HTTP 方法与路由声明**，包括两个始终返回空结果的录制接口。这是客户端不兼容变更：旧入口已不再注册，不提供重定向。仍调用旧路径的 Web/移动/TV 客户端或插件需要迁移；当前 [Docker 构建](Docker启动说明.md) 为固定版本 Web 提供局部适配补丁，[部分媒体页面仍未适配](../docker/Web兼容说明.md#已知未适配功能)；移动/TV 等独立客户端未迁移。

该轮移除后为 58 个控制器、367 条 HTTP 声明；后续[电视功能移除](电视直播与录像机移除说明.md)后，当前为 56 个控制器、324 条声明。只因隐藏于 OpenAPI 的入口没有被删除，例如动态 HLS、编码分片和内置 TMDb 配置。仍被当前 API 使用的领域服务、DTO、授权兼容选项和 `[ParameterObsolete]` 参数不属于本次整接口移除范围。

## 首次设置的新顺序

1. 未完成向导时，`POST /Startup/User`，JSON 必须含非空 `Password`，建议显式设置 `Name`，以便下一步按该用户名登录。该动作先调用 `IUserManager.InitializeAsync`；空数据库会创建首个管理员，已有用户沿用现有初始化规则。已有密码的用户仍禁止被此接口覆盖。
2. 用 `POST /Users/AuthenticateByName` 和 `Username` / `Pw` 认证，并携带 `Authorization: MediaBrowser Client="...", Device="...", DeviceId="...", Version="..."` 客户端信息。后续管理员请求携带响应的 Token。
3. 读取 `GET /System/Configuration`，更新需要的字段，再将完整配置提交至 `POST /System/Configuration`。配置接口替换整个对象，不能直接发送已删除的 `StartupConfigurationDto` 四字段 JSON。网络设置同样先读取 `GET /System/Configuration/network`，再更新提交，避免覆盖其他配置。
4. 设置完成后 `POST /Startup/Complete`。向导完成后，匿名调用初始化接口会被拒绝。

必要初始化原先只在已弃用 `GET /Startup/User` / `FirstUser` 内触发，本次迁至保留的 POST。实现见 [StartupController](../Jellyfin.Api/Controllers/StartupController.cs)；首次创建、密码保护和认证/配置流程分别由[单测](../tests/Jellyfin.Api.Tests/Controllers/StartupControllerTests.cs)和[集成测试](../tests/Jellyfin.Server.Integration.Tests/Controllers/StartupControllerTests.cs)覆盖。

## 音乐分类不是完全等价迁移

- `/Persons` 操作演职人员的数据表；不能照旧 Obsolete 提示把它当成音乐艺术家列表。`/Items?includeItemTypes=MusicArtist&recursive=true` 能查询通用艺术家条目，但不保证旧 Artists 的名称聚合、父库统计和计数语义。
- 旧 AlbumArtists 按作品的专辑艺术家关系聚合，当前未确认可一步替代的公开接口。`albumArtistIds` 用于筛选某位艺术家的作品，不是“只返回专辑艺术家”的开关。若客户端仍需要这一视图，可在完整分页并处理用户可见范围后，聚合 MusicAlbum/Audio DTO 的 `AlbumArtists`；这需要客户端适配。
- `/Genres?parentId=<音乐库ID>` 根据父库类型走音乐流派查询；省略 parentId 或指向其他库不保证相同结果。`/Genres/{genreName}` 查询普通 Genre，并对缺失名称回退对象，不能视为旧 MusicGenre 的按名查询/404 行为。要取得音乐流派详情，先从列表取得 ID，再查 `/Items/{itemId}`。
- Songs、Albums、Playlists、Artists/{itemId}、Items/{itemId} 的 InstantMix 仍保留。使用流派名称的旧调用需先解析条目 ID。

源码依据：[GenresController](../Jellyfin.Api/Controllers/GenresController.cs)、[ItemsController](../Jellyfin.Api/Controllers/ItemsController.cs)、[PersonsController](../Jellyfin.Api/Controllers/PersonsController.cs)、[InstantMixController](../Jellyfin.Api/Controllers/InstantMixController.cs)。

## 同步清理的死代码

- 删除只包含弃用动作的 ArtistsController、MusicGenresController、TrailersController 三个文件，连同仅在各文件内使用的助手和依赖注入。
- 删除无剩余引用的 StartupConfigurationDto、StartupRemoteAccessDto；保留 POST 使用的 StartupUserDto。
- 删除其余十个控制器中的旧包装动作、旧播放上报转换代码及失效导入。共享的混播、用户和播放 DTO 仍由当前实现使用。`ILibraryManager.GetArtists(InternalItemsQuery)` / `GetAlbumArtists(InternalItemsQuery)` 已无仓内生产调用，但仍是未标记弃用的公共插件契约；本次保留，不能仅凭仓内引用数断言外部插件不再使用。
- 测试迁至当前 URL；移除重复参数行和原本没有注册过的两条用户歌词测试路径。原 MusicGenres 不存在名称的 404 用例改为有效 Genres 搜索返回 200 空结果，防止删除路由后产生假通过。

路由删除回归通过 ASP.NET MVC 实际动作注册检查旧声明消失，并检查关键保留路由仍存在；见 [DeprecatedRoutesTests](../tests/Jellyfin.Api.Tests/Controllers/DeprecatedRoutesTests.cs)。运行结果和限制见[手册核验记录](手册核验记录.md)。
